# Word-Man (command line installer)

[Word-Man](https://github.com/sinhamajoni06-cell/Pac-Man-Game) is a Pac-Man game with a word-finding mode.
This package installs the Windows game from the official GitHub release. It downloads the
installer, checks its SHA-256 hash and runs it.

```
wordman install            # download, check and run the installer
wordman install --silent   # no questions
wordman play               # start the game
wordman uninstall          # remove the game
wordman download [folder]  # only download and check the installer
```

The game is Windows only. If you only want to play, the simplest way is to download
`Wordman-Setup-vX.Y.Z.exe` from the [releases page](https://github.com/sinhamajoni06-cell/Pac-Man-Game/releases).

Word-Man is a fan-made project and is not affiliated with Bandai Namco.
